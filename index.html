Linear vs Logarithmic Class Distribution

Mathematical Cost-Sensitive Loss Weighting

Standard machine learning loss functions assume balanced class distribution ($50:50$). In credit card transactions, an unweighted algorithm achieves 99.83% accuracy by predicting class 0 constantly, completely failing to catch any fraudulent activity.

// Inverse Frequency Loss Formulation:
w_fraud = N / (2 * N_fraud) = 284807 / (2 * 492) = 289.4380
w_legit = N / (2 * N_legit) = 284807 / (2 * 284315) = 0.5009

By integrating weightCol="weight" into PySpark's Logistic Regression and Linear Support Vector Machine optimizers, the model is penalized 577 times more heavily for missing a fraud instance than for triggering a false alarm.
